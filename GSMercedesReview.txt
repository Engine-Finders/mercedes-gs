Font Family
Headings
Use:
Roboto Condensed
* Weight: 700–900 depending on hierarchy
* Style: Italic for H1/H2 where required
* Letter spacing: -0.5px
Example:
* H1 → Roboto Condensed 900 Italic
* H2 → Roboto Condensed 900 Italic
* H3 → Roboto Condensed 700/800
* H4 → Roboto Condensed 700
________________


Body & Supporting Text
Use the existing body font system:
Inter
* Body text → Inter Regular 400
* Buttons → Inter Semi Bold/Bold 600–700
* Labels → Inter Medium/Semi Bold 500–600
This keeps the premium automotive heading style while maintaining clean readability for paragraphs, cards, badges, and UI elements.
